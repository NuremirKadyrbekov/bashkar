# Группировка кассовых смен по дням

**Экран:** «Кассовая смена» в кабинете владельца Bashkar POS.

- Карточки активной и завершённых смен группируются по календарной дате открытия в часовом поясе `Asia/Bishkek`.
- Перед первой карточкой каждого дня показывается дата слева и тонкая малозаметная линия справа. Дата повторяется только при смене дня, в том числе между страницами истории.
- Активная смена остаётся первой; завершённые смены сохраняют текущий порядок от новых к старым. Содержимое карточек, отчёты и действия не меняются.
- Группировка применяется только для Owner. У остальных ролей отображение остаётся прежним.

**Приёмка:** несколько смен одного дня находятся под одной датой; смены соседних дней разделены; при загрузке следующей страницы дата не дублируется, если день продолжается.
