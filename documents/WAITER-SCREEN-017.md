# Экран официанта — сверка ТЗ и срез навигации

Дата: 27.10.2026. Основа: утверждённые R-C1…R-C8 в [BLOCK-C-TECH-UI-SPEC-001](BLOCK-C-TECH-UI-SPEC-001.md) §6, реализованный [API-WAITER-009](API-WAITER-009.md), поздние правила MATRIX/SET и исходники `apps/waiter-web/`.

## Что уже имеется

Отдельное ТЗ экрана **есть**: BLOCK-C-TECH-UI-SPEC-001 §6. Контракт API-WAITER-009 уточняет авторизацию, TABLE-права, зашифрованные локальные черновики, pending/receipt и ограничения HTTPS. Waiter Web уже содержит вход по PIN, список столов, посещение, меню, партии, коррекции, скидку, разрешённый расчёт, статус печати и восстановление неизвестного результата. Это локальная реализация; работа на реальных Android/iPhone и физическая печать относятся к отдельной аппаратной приёмке BLOCK-C-ACCEPTANCE-001.

## Проверяемый срез экрана

| Требование из §6 | Состояние до этого среза | Реализация |
|---|---|---|
| «Мои / Все» на столах | Все столы показаны без фильтра | Локальный фильтр по серверному `isMine`; «Все» включает свободные и занятые. Смена фильтра не расширяет доступ к деталям. |
| Поиск в каталоге | Категории есть, поиска нет | Поиск по названию блюда RU/KY без запроса нового меню и без изменения draft; скрываются пустые категории, есть пустое состояние. |
| Явный статус черновика | Заголовок «Новая партия» без статуса | Метка «Не отправлен»: пустой черновик или сохранённый на устройстве состав. После локального изменения прежнее сообщение «Принято сервером» очищается; принятые строки остаются в отдельной истории заказа. |
| Видимый focus / крупные действия | Минимальная высота уже задана | Явный keyboard focus и минимум 46 CSS px сохранены. |

Приёмка среза: фильтр использует только `isMine` из `/tables`; поиск не отправляет команд и не удаляет позиции; язык RU/KY меняет подписи, а черновик сохраняет содержимое; PIN/права/STRICT/SHARED, submit/receipt и расчёт работают прежним серверным путём. Следующие элементы §6, включая полную офлайн индикацию, описание ошибок записи черновика, статус кухни после отправки и проверку мобильных устройств, требуют отдельных срезов и проверки. Не считать их выполненными из-за этой навигации.
