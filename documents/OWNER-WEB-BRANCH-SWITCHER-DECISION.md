# Переключение филиалов владельца — решение

Статус: направление для будущего веб-сайта владельца; реализация не начата.

Решение пользователя от 03.11.2026: переключатель филиалов в Bashkar POS Desktop отменён. POS Desktop продолжает работать с одним локальным филиалом. Переключение между филиалами планируется только для веб-сайта владельца.

Перед разработкой веб-сайта необходимо отдельно согласовать состав доступных данных и действий, источник данных каждого филиала и правила доступа владельца. Этот документ не является ТЗ на реализацию.
