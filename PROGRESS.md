## 27.10.2026 — Waiter Web: явный локальный HTTP для MVP

- По выбору пользователя добавлен включаемый через `BASHKAR_WAITER_HTTP_IP`/`BASHKAR_WAITER_HTTP_PORT` HTTP listener только на частном IPv4. Desktop показывает HTTP URL/QR и предупреждение о незашифрованном трафике. Native API по-прежнему только loopback, HTTPS-профиль не удаляется; при неверном HTTP IP/порте native POS продолжает работать.
- Для HTTP браузера без SubtleCrypto используется уже установленный `node-forge` AES-GCM/SHA-256 в прежнем формате encrypted IndexedDB; UUID/IV берутся из `crypto.getRandomValues`. Сохранены PIN, серверные права, exact Host/Origin, CSRF, memory unlock, durable pending/receipt. HTTP cookie имеет отдельное имя и не претендует на `Secure`.
- `pnpm run check`, `pnpm test` **227/37 PASS**, `pnpm run test:waiter-http` и прежний `pnpm run test:service-clients-desktop` PASS на временных БД/профилях. HTTP QA пройден и на текущем частном IP Mac с `isSecureContext=false`, и на loopback с отключёнными SubtleCrypto/randomUUID/service worker; Desktop показал HTTP URL/QR. Android/iPhone, рабочая сеть и реальные принтеры не проверялись. Рабочие профили, ключи и MANGO не менялись. [Режим, запуск и ограничения](documents/WAITER-HTTP-MVP-018.md).

## 27.10.2026 — POS-016: частичная выдача через счётчик

- Галочка у отправленной позиции заменена синим счётчиком «Выдано 3 / 5». Плюс отмечает одну единицу, минус исправляет отметку; границы 0…currentQuantity, отдельный стиль от жёлтой сборки. Права `order.fulfillment.mark`, закрытое состояние и pending блокируют соответствующие элементы.
