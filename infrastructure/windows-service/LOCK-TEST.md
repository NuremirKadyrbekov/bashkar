# Отдельный тест новой блокировки и перезапуска Windows-службы

Это тест на пустой отдельной базе. Он не обновляет и не останавливает установленную BashkarPOSPrototype. Использует отдельную службу BashkarPOSLockTest, отдельные каталоги Program Files/ProgramData и порт 3211. Не применять к реальному филиалу. При существующих каталогах или службе установщик откажется работать. Временно настроены две попытки восстановления (5 и 15 секунд), затем прекращение попыток; сброс счётчика через час. Реальное поведение SCM требуется проверить.

Из папки распакованного архива в PowerShell администратора:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
Start-Service BashkarPOSLockTest
Get-Service BashkarPOSLockTest
curl.exe -s http://127.0.0.1:3211/api/v1/system/health/live
curl.exe -s -i http://127.0.0.1:3211/api/v1/system/health/ready
```

Ожидаются Running, live, 503/NEEDS_ACTIVATION. Если этого нет, остановиться и сохранить вывод и журналы. Первую проверку аварии выполнять только по отдельным инструкциям после подтверждения запуска. Автоматическая служебная регистрация, ACL, перезапуск, поведение при сбое и отказе пока не проверены на Windows. По завершении теста остановить и удалить только эту тестовую службу; данные не стираются автоматически.
